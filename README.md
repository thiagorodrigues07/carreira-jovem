# Carreira Jovem

Site estático de apresentação de oportunidades para quem busca a primeira experiência em tecnologia, com páginas sobre vagas, cursos e contato.

## Tecnologias

HTML5, CSS e imagens locais. Não utiliza framework.

## Como executar

Abra `index.html` em um navegador moderno. Não é necessária instalação.

## Exemplo de uso

Navegue até Oportunidades para visualizar as categorias de vagas e cursos.

## Objetivo de aprendizagem

Praticar estruturação de páginas, navegação e estilização de um pequeno portal.

## Publicar com GitHub Pages

Em **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e `/(root)`. Depois do primeiro deploy, o site ficará em https://thiagorodrigues07.github.io/carreira-jovem/.
